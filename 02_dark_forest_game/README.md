# Анализ монетизации и поведения игроков (RPG «Секреты Тёмнолесья»)

## О проекте
Исследовательский и ad-hoc анализ данных внутриигровых покупок с целью оценки активности игроков, выявления аномалий и сегментации пользователей по расам персонажей для оптимизации монетизации.

## Инструменты
* **Базы данных:** SQL (Postgres)
* **Инструменты:** DBeaver

## Ключевые инсайты
* **Стабильная монетизация:** Доля платящих игроков стабильна и составляет **18%** вне зависимости от расы персонажа.
* **Разные паттерны трат:** 
  - **Human:** совершают много дешевых покупок (в среднем 121 транзакция по ~403 ед. валюты).
  - **Northman:** совершают меньше покупок, но с высоким средним чеком (82 транзакции по ~761 ед. валюты).
* **Дисбаланс ассортимента:** Два эпических предмета (*Book of Legends* и *Bag of Holding*) формируют **98%** всех покупок, указывая на то, что остальной ассортимент практически не востребован.

## Продуктовые рекомендации
1. **Таргетированные механики:** Внедрить скидки на объем («купи 3 по цене 2») для аудитории Human и эксклюзивные премиум-бандлы для Northman.
2. **Ротация ассортимента:** Стимулировать покупку непопулярных предметов через временные акции или бонусы, чтобы снизить зависимость выручки от двух позиций.
